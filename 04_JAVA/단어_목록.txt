CGI(Common Gateway Interface)
- 요청이 올때마다 새로운 프로세스를 생성하는 방식 (외부프로그램을 통해)

1997년 Servelet 등장 - 자바로 HTTP 요청을 처리
프로그램 하나만 켜두고 요청이 오면 쓰레드만 새로 생성해서 처리
ex> System.out.println("<h1> 안녕하세요 </h1>"); - 아직 복잡하다.

(2000 ~) JSP(Java Server Pages) 등장.
HTML 기반 파일에 <% 자바코드 %>
HTML은 디자이너가 하고, 자바 로직은 개발자가 작성
동적 데이터 바인딩 가능
여전히 프론트엔드와 백엔드의 소통이 어렵고 코드가 어려움
<html> <body>
	<h1> 안녕하세요, <%= request.getParameter("name") %> 님! </h1>
</body> </html>

<MVC 구조>
Controller - 중간 다리 역할
View - 화면
Model - 데이터 및 로직

유지보수성이 향상

ex) 회원가입 흐름
1. 화면(UI) 로직 : HTML 폼에서 이름, 이메일, 비밀번호 입력 후 "가입" 버튼 클릭 (주소)
2. (주소로 받아서) Controller: 요청을 받아서 (메서드 실행) Service 계층 호출
3. Service 계층(비지니스 로직) :
	- 비밀번호 암호화
	- 이메일 중복 여부 확인
	- 이메일 형식 검증
	- 가입 완료 시 환영 메일 발송
4. DAO/Repo 계층 (데이터 접근)
	- DB에 연결하여 INSERT 쿼리 실행

Spring - 자바 웹 개발을 쉽게 하게끔 도와주는 프레임워크
 - 의존성 주입
 - 제어의 역전
 - 관점 지향 프로그래밍

SpringBoot - 스프링 사용을 쉽게 해 주는(한 방에) 프로젝트

DB 쪽 :
JDBC(Java DataBase Connectivity) - 
ex) String sql = "INSERT INTO employee (name, age) VALUSE (? , ?)";

JPA - SQL 작성 없이 객체(Entity) 중심 개발
- CRUD 기능을 기본적으로 제공 (CREATE READ UPDATE DELETE)
