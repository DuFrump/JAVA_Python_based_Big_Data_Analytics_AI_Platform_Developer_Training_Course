# Day10 학습 정리

Day10에서는 자바의 '내부 클래스(Inner Class)'와 '예외 처리(Exception Handling)'에 대해 심도 있게 학습했습니다.

## 주요 학습 내용:

1.  **내부 클래스 (Inner Class) (_01_InstanceClass.java, _02_StaticClass.java, _03_LocalClass.java, _04_ClassPermit.java)**
    *   **인스턴스 내부 클래스**: 바깥 클래스의 인스턴스에 종속되며, 바깥 클래스의 모든 멤버에 접근 가능함을 학습했습니다.
    *   **정적 내부 클래스**: `static` 키워드로 선언되며, 바깥 클래스의 인스턴스 없이도 생성 가능하고, 바깥 클래스의 `static` 멤버에만 접근 가능함을 이해했습니다.
    *   **지역 내부 클래스**: 메소드나 블록 내에서 선언되며, 해당 블록 내에서만 유효하고, `final` 또는 `effectively final` 지역 변수에 접근 가능함을 파악했습니다.
    *   **접근 제어**: `private` 내부 클래스를 통해 캡슐화를 강화하고, 외부에서 특정 메소드를 통해서만 접근하도록 제어하는 방법을 배웠습니다.

2.  **익명 내부 클래스 (Anonymous Inner Class) (_05_AnonymousClass1.java, _06_AnonymousClass2.java, AnonymousClassEX.java)**
    *   **정의**: 이름이 없는 클래스로, 클래스 정의와 객체 생성을 동시에 수행하는 일회성 클래스임을 학습했습니다.
    *   **활용**: 주로 인터페이스를 즉석에서 구현하거나 추상 클래스를 상속받아 메소드를 바로 재정의할 때 사용됨을 이해했습니다.
    *   **실전 예제**: `Coffee` 클래스 메소드 오버라이딩, `buttonClickListener` 인터페이스 구현을 통해 익명 클래스가 이벤트 처리나 콜백 패턴에서 어떻게 유용하게 사용되는지 실습했습니다.

3.  **주요 런타임 예외 (Runtime Exception) (_08_NullPointException.java, _09_NumberFormatException.java, _10_ArrayIndexOutOfBoundsException.java)**
    *   **`NullPointerException`**: `null` 참조에 접근하려 할 때 발생하는 예외와 이를 피하는 방법을 배웠습니다.
    *   **`NumberFormatException`**: 문자열을 숫자로 변환할 때 형식 불일치로 발생하는 예외를 이해했습니다.
    *   **`ArrayIndexOutOfBoundsException`**: 배열의 유효 인덱스 범위를 벗어날 때 발생하는 예외를 학습했습니다.

4.  **예외 처리 (Exception Handling) (_11_TryCatch.java, _12_TryCatch2.java, _13_TryCatch3.java, _14_Exception.java, _15_Finally.java, _16_ThrowException.java)**
    *   **`try-catch`**: 예외 발생 가능성이 있는 코드를 `try` 블록에, 예외 발생 시 처리할 코드를 `catch` 블록에 작성하여 프로그램의 비정상 종료를 방지하는 방법을 배웠습니다.
    *   **다중 `catch`**: 여러 종류의 예외를 각각 다른 `catch` 블록으로 처리하는 방법과, 구체적인 예외부터 일반적인 예외 순서로 작성해야 함을 학습했습니다.
    *   **`Exception` 클래스**: 모든 예외의 최상위 부모인 `Exception`을 사용하여 모든 종류의 예외를 잡는 방법을 이해하고, 사용 시 주의할 점을 파악했습니다.
    *   **`finally`**: 예외 발생 여부와 관계없이 항상 실행되어야 하는 코드를 포함하는 `finally` 블록의 역할을 배웠습니다. 주로 자원 정리(예: `Scanner.close()`)에 사용됨을 강조했습니다.
    *   **`throw`와 `throws`**: 개발자가 직접 예외를 발생시킬 때 사용하는 `throw` 키워드와, 메소드에서 발생 가능한 예외를 선언하여 호출자에게 처리 책임을 전가하는 `throws` 키워드의 사용법을 학습했습니다.

Day10 학습을 통해 자바의 고급 문법인 내부 클래스를 이해하고, 프로그램의 안정성을 높이는 필수적인 예외 처리 기법을 마스터했습니다.
