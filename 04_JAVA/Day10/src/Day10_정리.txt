_01_InstanceClass.java — 인스턴스 내부 클래스
인스턴스 내부 클래스의 개념과 사용법을 설명합니다. 바깥 클래스의 객체가 있어야만 생성하고 사용할 수 있으며, 바깥 클래스의 인스턴스 변수와 static 변수에 자유롭게 접근할 수 있음을 `Calculator`와 `Calc` 클래스 예시를 통해 보여줍니다.

_02_StaticClass.java — 정적 내부 클래스 (Static Inner Class)
정적 내부 클래스의 개념과 사용법을 설명합니다. `static` 키워드가 붙어 바깥 클래스의 객체 생성 없이 독립적으로 사용할 수 있으며, 바깥 클래스의 static 멤버에는 접근 가능하지만 인스턴스 멤버에는 접근할 수 없음을 `PrintOut`과 `Out` 클래스 예시를 통해 보여줍니다.

_03_LocalClass.java — 지역 내부 클래스 (Local Inner Class)
지역 내부 클래스의 개념과 사용법을 설명합니다. 특정 메소드 블록 안에서만 선언되고 사용되며, 자신을 감싸고 있는 메소드의 매개변수나 바깥 클래스의 멤버에 접근할 수 있음을 `getUnit` 메소드 안의 `Unit` 클래스 예시를 통해 보여줍니다.

_04_ClassPermit.java — 내부 클래스의 접근 제어와 캡슐화
`private`으로 선언된 내부 클래스가 외부에서 직접 접근할 수 없지만, 바깥 클래스가 허용하는 메소드를 통해서만 간접적으로 사용할 수 있음을 보여줍니다. 이를 통해 내부의 복잡한 구조는 숨기고 허용된 기능만 외부에 노출하는 캡슐화 개념을 설명합니다.

_05_AnonymousClass1.java — 익명 내부 클래스 (Anonymous Inner Class) 기본
익명 내부 클래스의 기본 개념을 설명합니다. 이름이 없는 클래스로, 클래스 정의와 객체 생성을 동시에 하여 딱 한 번만 사용할 클래스를 만들 때 유용함을 보여줍니다. `Coffee` 클래스를 예시로 일반적인 객체 생성과 익명 클래스를 통한 메소드 오버라이딩을 비교합니다.

_06_AnonymousClass2.java — 인터페이스와 익명 클래스 활용 (이벤트 처리)
인터페이스와 익명 클래스를 함께 사용하여 이벤트 처리 패턴을 구현하는 실전 예제입니다. `buttonClickListener` 인터페이스를 정의하고, `Button` 클래스에서 이 인터페이스를 통해 기능을 주입받아 실행하는 방식을 보여줍니다. 이는 "어떤 일이 일어났을 때, 어떤 행동을 할지"를 분리하는 중요한 디자인 패턴을 설명합니다.
