_01_Variables.java — 변수와 Scanner를 활용한 입출력
Scanner 클래스를 사용하여 사용자로부터 이름, 날씨, 시간 등을 입력받고, 다양한 데이터 타입(String, int, double, char, short, boolean)의 변수를 선언 및 활용하여 출력하는 예제입니다. printf()를 이용한 형식 지정 출력도 포함합니다.

_02_Scanner.java — Scanner 입력 주의사항 (nextInt()/nextDouble() vs nextLine())
Scanner를 사용하여 다양한 데이터 타입(String, double, int)의 사용자 입력을 받는 방법을 설명합니다. 특히 nextInt(), nextDouble() 등 숫자 입력 메소드 사용 후 nextLine() 사용 시 발생하는 개행 문자(엔터) 문제를 해결하는 방법을 다룹니다.

_03_Operator.java — 중첩된 삼항 연산자
기본적인 삼항 연산자(조건 ? 참 : 거짓)와 이를 중첩하여 세 가지 경우(크다/작다/같다)를 판별하는 방법을 설명합니다. if-else if-else 문과 비교하여 삼항 연산자의 활용을 보여줍니다.

_04_Scanner_Operator.java — Scanner와 삼항 연산자 활용
Scanner를 사용하여 사용자로부터 두 개의 숫자를 입력받고, 중첩된 삼항 연산자를 활용하여 두 숫자의 크기를 비교하고 결과를 출력하는 예제입니다.

_05_String1.java — String 클래스 메소드 (길이, 대소문자, 포함, 위치, 시작/끝)
String 클래스의 주요 메소드들을 소개합니다. length(), toUpperCase(), toLowerCase(), contains(), indexOf(), lastIndexOf(), startsWith(), endsWith() 메소드의 사용법과 반환 값을 예시와 함께 설명합니다.

_06_String2.java — String 클래스의 추가적인 메소드들을 다룹니다. replace(), substring(), trim(), concat() 메소드를 사용하여 문자열을 교체하거나, 부분 문자열을 추출하거나, 공백을 제거하거나, 문자열을 결합하는 방법을 보여줍니다.

_07_StringCompare.java — 문자열 비교 (equals() vs ==)
자바에서 문자열을 비교하는 올바른 방법(equals() 메소드)과 주의해야 할 `==` 연산자의 차이점을 설명합니다. `equals()`는 문자열의 내용을 비교하고, `==`는 메모리 주소를 비교함을 강조하며, `equalsIgnoreCase()`도 소개합니다.

_08_EscapeSequence.java — 이스케이프 시퀀스
이스케이프 시퀀스(\n, \t, \\, \", \')의 사용법을 설명합니다. 줄바꿈, 탭, 역슬래시, 큰따옴표, 작은따옴표 등 특수 문자를 문자열 내에 표현하는 방법을 예시와 함께 보여줍니다.

_09_Quiz.java — 주민등록번호 정보 추출 퀴즈
주민등록번호 문자열에서 `substring()` 메소드를 사용하여 생일과 성별 정보를 추출하고, 조건 연산자(삼항 연산자)와 `equals()` 메소드를 사용하여 성별을 판별하여 출력하는 퀴즈 예제입니다.

_10_If1.java — 조건문 if, if-else if-else
조건문 `if`의 기본적인 사용법과 `if-else if-else` 구조를 설명합니다. 특정 조건이 참일 때 코드 블록을 실행하거나, 여러 조건 중 하나를 선택적으로 실행하는 방법을 보여줍니다.

_11_If2.java — if-else if와 논리 연산자
`if-else if` 조건문과 논리 연산자(`||`, OR)를 활용하는 예제입니다. 여러 조건을 조합하여 특정 상황에 따라 다른 코드를 실행하는 방법을 보여줍니다.

_12_IfElse.java — 조건문 if-else
조건문 `if-else`의 사용법을 설명합니다. 조건식이 참일 때와 거짓일 때 각각 다른 코드 블록을 실행하는 기본적인 구조를 보여줍니다.

_13_IfElse_Max.java — if-else를 이용한 최대값 찾기
두 개의 정수 중 더 큰 값을 `if-else` 문을 사용하여 찾아내고 출력하는 간단한 예제입니다.

_14_IfQuiz.java — if-else를 이용한 성인/미성년자 판별 퀴즈
사용자로부터 나이를 입력받아 `if-else` 문을 사용하여 성인 또는 미성년자를 판별하여 출력하는 퀴즈 예제입니다.

_15_Else_If.java — else if를 이용한 다중 조건 처리
`else if`를 사용하여 여러 개의 조건을 순차적으로 검사하고, 해당 조건에 맞는 코드 블록을 실행하는 방법을 보여줍니다. 좋아하는 숫자 비교와 나이에 따른 분류 예제를 포함합니다.

_16_Else_If2.java — else if를 이용한 메뉴 선택 예제
`else if`를 사용하여 특정 조건(메뉴 선택)에 따라 다른 메시지를 출력하는 간단한 예제입니다.

_17_Switch.java — switch 문 기본 사용법
`switch` 문의 기본적인 사용법을 설명합니다. 특정 변수의 값에 따라 여러 `case` 중 하나를 선택적으로 실행하는 방법을 보여주며, `break` 키워드와 `default`의 역할을 설명합니다.

_18_Switch2.java — switch 문 (case 여러 개, if-else if-else 비교)
`switch` 문에서 여러 `case`를 묶어서 처리하는 방법(Java 14 이상)을 보여줍니다. `if-else if-else` 문과 비교하여 동일한 로직을 `switch` 문으로 구현하는 예제를 통해 두 조건문의 차이점을 이해하도록 돕습니다.

_19_Switch3.java — switch 문 (fall-through)
`switch` 문에서 `break` 키워드를 사용하지 않았을 때 발생하는 'fall-through' 현상을 설명합니다. 특정 `case`가 실행된 후 `break`가 없으면 다음 `case`의 코드도 이어서 실행되는 동작을 보여줍니다.

_20_lastQuiz.java — 주차 요금 계산 퀴즈 (if 문 활용)
사용자로부터 주차 시간, 경차 여부, 장애인 차량 여부를 입력받아 주차 요금을 계산하는 퀴즈 예제입니다. `if` 문을 사용하여 최대 요금 제한 및 경차/장애인 차량 할인 로직을 적용합니다.
