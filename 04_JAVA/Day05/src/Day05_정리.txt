# Day05 학습 정리

Day05에서는 배열의 심화 학습과 함께 객체 지향 프로그래밍(OOP)의 핵심 개념들을 클래스 예제를 통해 깊이 있게 다루었습니다.

## 주요 학습 내용:

1.  **배열 심화 및 활용 (_01_Array3.java, _02_MultiArray2.java, _03_Quiz.java, _04_Bubble.java, _05_ForUpgrade.java)**
    *   **char 배열**: 문자의 유니코드/아스키 코드 값을 활용하여 `char` 배열에서 알파벳을 추출하고 문자열로 조합하는 방법을 배웠습니다.
    *   **2차원 배열**: 정방형 배열과 가변 배열(Jagged Array)의 생성 및 순회 방법을 심화 학습하고, 좌석 배치도 생성과 같은 응용 예제를 실습했습니다.
    *   **배열 활용 퀴즈**: 신발 사이즈 목록 생성 퀴즈를 통해 배열과 반복문을 결합하여 실생활 데이터를 다루는 연습을 했습니다.
    *   **버블 정렬**: 가장 기본적인 정렬 알고리즘인 버블 정렬의 원리(인접 요소 비교 및 교환)와 중첩 `for`문을 통한 구현 방법을 이해했습니다.
    *   **향상된 `for`문 (for-each)**: 배열의 모든 요소를 간결하게 순회하는 `for (타입 변수 : 배열)` 문법을 배우고, 일반 `for`문과의 차이점 및 적절한 사용 시점을 파악했습니다.

2.  **객체 지향 프로그래밍 (OOP) 기초 (_ClassBlackbox, _ClassEx, _pet 폴더 내 파일들)**
    *   **클래스와 객체**: 클래스가 객체의 '설계도'이며, 객체가 그 설계도로 만들어진 '제품'임을 이해했습니다.
    *   **인스턴스 변수**: 각 객체마다 고유한 값을 가지는 변수(예: `modelName`, `name`, `age`)의 개념을 학습했습니다.
    *   **클래스 변수 (`static`)**: 모든 객체가 공유하는 단 하나의 변수이며, `static` 키워드로 선언됨을 배웠습니다. (`BlackBox.canAutoReport`, `Dog.bark`)
    *   **메소드**: 객체가 수행할 수 있는 '동작'이나 '기능'을 정의하는 방법을 익혔습니다. (반환값 유무, 파라미터 유무)
    *   **메소드 오버로딩**: 메소드 이름은 같지만 파라미터의 개수나 타입이 다른 여러 메소드를 정의하여 사용자의 편의성을 높이는 방법을 배웠습니다. (`BlackBox.record()`, `Cat.feed_unga()`)
    *   **클래스 메소드 (`static` 메소드)**: 객체 생성 없이 `클래스이름.메소드이름()`으로 직접 호출 가능한 메소드이며, `static` 변수만 접근 가능함을 이해했습니다. (`BlackBox.callServiceCenter()`)
    *   **`this` 키워드**: '이 객체 자신'을 가리키는 `this` 키워드를 사용하여 인스턴스 변수와 파라미터의 이름이 같을 때 구분하는 방법을 배웠습니다.
    *   **생성자**: 객체 생성 시 자동으로 호출되어 초기화 작업을 수행하는 생성자의 역할, 기본 생성자, 오버로딩된 생성자, 그리고 `this()`를 이용한 생성자 체이닝을 학습했습니다.
    *   **캡슐화 (Encapsulation)와 Getter/Setter**: 객체의 데이터를 `private`으로 보호하고, `public` `Getter`와 `Setter` 메소드를 통해 안전하게 접근하도록 제어하는 캡슐화의 중요성을 이해했습니다. (`BlackBox.setPrice()`, `Dog.setAge()`)
    *   **실전 예제**: `BlackBox`, `Dog`, `Cat` 클래스들을 직접 설계하고, `Main` 클래스에서 객체를 생성하여 상호작용하는 과정을 통해 OOP의 기본 원리들을 통합적으로 실습했습니다.

Day05 학습을 통해 자바의 배열을 능숙하게 다루고, 객체 지향 프로그래밍의 핵심 개념들을 실제 클래스 설계에 적용하는 기초를 탄탄히 다졌습니다.
