_02_MultiArray2.java — 다차원 배열 활용 (좌석 배치)

_03_Quiz.java — 배열을 이용한 신발 사이즈 목록 생성 퀴즈
배열을 사용하여 신발 사이즈 목록을 생성하고 출력하는 퀴즈 예제입니다. 특정 범위(250부터 295까지 5단위)의 숫자를 배열에 저장하고 반복문을 통해 출력하는 방법을 보여줍니다.

_04_Bubble.java — 버블 정렬(Bubble Sort) 구현
버블 정렬 알고리즘을 사용하여 배열을 오름차순으로 정렬하는 예제입니다. 인접한 두 요소를 비교하여 위치를 교환하는 과정을 중첩 반복문을 통해 구현하고, 정렬된 배열을 출력합니다.

_05_ForUpgrade.java — 향상된 for 문 (Enhanced For Loop)
향상된 for 문(for-each 문)의 사용법을 설명합니다. 배열의 모든 요소를 순회할 때 인덱스를 사용하지 않고 간결하게 코드를 작성하는 방법을 보여줍니다. 점수 배열의 합계 및 평균 계산, 문자열 배열 출력 예제를 포함합니다.

ClassBlackbox/_01_InstanceVariables.java — 인스턴스 변수

ClassBlackbox/_02_ClassVariables.java — 클래스 변수 (static 변수)

ClassBlackbox/_03_Method.java — 메소드 활용

ClassBlackbox/_04_MethodOverloading.java — 메소드 오버로딩

ClassBlackbox/_05_ClassMethod.java — 클래스 메소드 (static 메소드)
클래스 메소드(static 메소드)의 개념과 사용법을 설명합니다. 객체 생성 없이 클래스 이름으로 직접 호출할 수 있으며, 주로 유틸리티 기능이나 모든 객체에 공통적으로 적용되는 기능을 구현할 때 사용됨을 `BlackBox.callServiceCentre()` 예시를 통해 보여줍니다.

ClassBlackbox/_06_This.java — this 키워드
`this` 키워드의 사용법을 설명합니다. 주로 인스턴스 변수와 매개변수의 이름이 같을 때 인스턴스 변수를 명확히 지칭하거나, 현재 객체의 다른 메소드를 호출할 때 사용됨을 `BlackBox.appendModelName()` 예시를 통해 보여줍니다.

ClassBlackbox/_07_Constructor.java — 생성자 (Constructor)
생성자의 개념과 사용법을 설명합니다. 객체가 생성될 때 초기화를 담당하며, 여러 개의 생성자를 정의하여 다양한 방식으로 객체를 초기화할 수 있음을 `BlackBox` 클래스의 기본 생성자와 매개변수 있는 생성자를 통해 보여줍니다. `this()`를 이용한 다른 생성자 호출도 포함합니다.
