_01_For1.java — for 반복문 기본
for 반복문의 기본적인 사용법을 설명합니다. 초기화, 조건, 증감식을 이용한 반복 실행과 합계 계산, 특정 조건(짝수)에 맞는 값만 합산하는 예제를 포함합니다.

_02_For2.java — 중첩 for 반복문과 구구단
중첩 for 반복문의 사용법을 보여줍니다. 내부 반복문과 외부 반복문의 관계를 설명하고, 이를 활용하여 세로 구구단과 가로 구구단을 출력하는 예제를 제공합니다.

_03_Pyramid.java — 중첩 for 반복문을 이용한 별 피라미드
중첩 for 반복문을 사용하여 다양한 형태의 별 피라미드(삼각형, 역삼각형, 다이아몬드 등)를 출력하는 예제입니다. 공백과 별의 개수를 조절하여 패턴을 만드는 방법을 보여줍니다.

_04_While1.java — while 반복문
while 반복문의 기본적인 사용법을 설명합니다. 조건식이 참인 동안 코드 블록을 반복 실행하는 구조와 합계 계산 예제를 포함합니다.

_05_DoWhile.java — do-while 반복문
do-while 반복문의 기본적인 사용법을 설명합니다. 최소 한 번은 코드 블록을 실행한 후 조건식을 검사하여 반복 여부를 결정하는 구조와 합계 계산 예제를 포함합니다.

_06_Continue.java — continue 문
continue 문의 사용법을 설명합니다. 반복문 내에서 continue를 만나면 현재 반복을 건너뛰고 다음 반복을 계속 진행하는 동작을 보여줍니다. 짝수의 합을 계산하는 예제를 통해 continue의 활용을 보여줍니다.

_07_Break.java — break 문
break 문의 사용법을 설명합니다. 반복문 내에서 break를 만나면 반복문을 즉시 종료하고 반복문 다음 코드를 실행하는 동작을 보여줍니다. 특정 조건(판매량 최대치)에 도달하면 반복을 중단하는 예제를 포함하며, continue와 함께 사용하여 노쇼 손님을 처리하는 시나리오를 보여줍니다.

_08_Array.java — 배열(Array) 기본
배열의 선언, 초기화, 값 할당 및 접근 방법을 설명합니다. String 배열과 int 배열의 사용 예시를 보여주며, 배열의 길이(length) 속성을 활용하는 방법을 포함합니다.

_09_Array2.java — 배열과 난수, 짝수 합산
배열에 난수(random number)를 생성하여 저장하고, 배열 내의 짝수만 합산하는 예제입니다. `Math.random()`을 사용하여 난수를 생성하고, `while(true)` 무한 루프와 `break`를 사용하여 특정 조건(짝수 합산이 0)이 될 때까지 반복하는 시나리오를 보여줍니다.

_10_ArrayQuiz.java — 배열을 이용한 로또 시뮬레이션 퀴즈
배열과 난수를 활용하여 로또 당첨 번호를 시뮬레이션하는 퀴즈 예제입니다. 정답 번호 배열과 사용자가 생성한 번호 배열을 비교하여 일치하는 번호의 개수를 세고, 6개 모두 일치할 때까지 반복하는 로직을 구현합니다.

_11_Arrays.java — Arrays 클래스 유틸리티 메소드
`java.util.Arrays` 클래스의 유용한 유틸리티 메소드들을 소개합니다. `Arrays.toString()`을 사용하여 배열의 내용을 문자열로 출력하는 방법과 `Arrays.sort()`를 사용하여 배열을 정렬하는 방법을 보여줍니다. 또한 배열 복사 시 참조 복사와 값 복사(`Arrays.copyOf()`)의 차이점을 설명합니다.

_12_MultiArray.java — 다차원 배열 (2차원 배열)
다차원 배열, 특히 2차원 배열의 선언, 초기화, 값 할당 및 접근 방법을 설명합니다. 행과 열의 개념을 이해하고, `length` 속성을 사용하여 2차원 배열의 행과 각 행의 열 길이를 얻는 방법을 보여줍니다. 가변 배열(jagged array)의 개념도 간략하게 소개합니다.
