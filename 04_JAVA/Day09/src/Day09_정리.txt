DeliveryApp.java — 다형성을 활용한 배달 앱 주문 시스템
`Menu` 부모 클래스를 상속받는 `Chicken`, `Pizza`, `Jokbal` 클래스를 구현하여 다형성을 활용한 주문 시스템을 만듭니다. 사용자의 메뉴 선택에 따라 오버라이딩된 `order()` 메소드가 실행되며, `Scanner`를 이용한 사용자 입력과 반복적인 주문 처리를 포함합니다.

_01_Receipt/Main.java — 추상 클래스 활용 (레시피)
`Recipe` 추상 클래스를 상속받는 `PastaRecipe`와 `StakeRecipe` 클래스를 활용하는 메인 클래스입니다. 추상 클래스는 직접 객체 생성이 불가능하며, 자식 클래스에서 구현된 메소드를 호출하여 다형성을 보여줍니다.

_01_Receipt/PastaRecipe.java — Recipe 추상 클래스 상속 (파스타 레시피)
`Recipe` 추상 클래스를 상속받는 `PastaRecipe` 클래스입니다. 파스타를 만드는 고유한 메소드 `makePasta()`를 가집니다.

_01_Receipt/Recipe.java — 추상 클래스 정의 (레시피)
요리사의 이름(chef)을 속성으로 가지며, `info()` 메소드를 통해 레시피 정보를 출력하는 추상 클래스입니다. 추상 클래스는 직접 객체 생성이 불가능하며, 자식 클래스에서 특정 메소드를 구현하도록 강제할 수 있습니다.

_01_Receipt/StakeRecipe.java — Recipe 추상 클래스 상속 (스테이크 레시피)
`Recipe` 추상 클래스를 상속받는 `StakeRecipe` 클래스입니다. 스테이크를 굽는 고유한 메소드 `grillStake()`를 가집니다.

_02_Phone/Main.java — 추상 클래스 활용 (핸드폰)
`Phone` 추상 클래스를 상속받는 `PineapplePhone` 클래스를 활용하는 메인 클래스입니다. 추상 클래스의 메소드를 호출하여 핸드폰의 전원 켜고 끄기, 로고 표시 등의 동작을 보여줍니다.

_02_Phone/Phone.java — 추상 클래스 정의 (핸드폰)
핸드폰의 기본적인 동작(전원 켜기/끄기, 로고 표시)을 정의하는 추상 클래스입니다. `openingLogo()` 메소드는 추상 메소드로 선언되어 자식 클래스에서 반드시 구현하도록 강제합니다.

_02_Phone/PineapplePhone.java — Phone 추상 클래스 상속 (파인애플 폰)

_03_Phone2/Main.java — 인터페이스와 다형성 활용 (핸드폰 교체 시뮬레이션)
`Phone` 인터페이스를 구현하는 `PineapplePhone2`와 `ThreeStarPhone2` 클래스를 활용하여 사용자가 핸드폰을 사용하고 교체하는 시뮬레이션을 보여줍니다. 인터페이스를 통해 다양한 종류의 핸드폰을 일관된 방식으로 다루는 다형성을 강조합니다.

_03_Phone2/Person.java — 핸드폰을 사용하는 사람 클래스
`Phone` 인터페이스 타입의 핸드폰 객체를 가지는 `Person` 클래스입니다. 핸드폰을 켜고 끄고, 유튜브를 시청하고, 충전하는 등의 동작을 수행하며, 새로운 핸드폰으로 교체하는 기능도 포함합니다.

_03_Phone2/Phone.java — 인터페이스 정의 (핸드폰)
핸드폰의 필수적인 기능(전원 켜기/끄기, 전원 상태 확인, 유튜브 시청, 충전)을 정의하는 인터페이스입니다. `MAX_BATTERY_CAPACITY`와 같은 상수를 정의할 수 있습니다.

_03_Phone2/PineapplePhone2.java — Phone 인터페이스 구현 (파인애플 폰 2)
