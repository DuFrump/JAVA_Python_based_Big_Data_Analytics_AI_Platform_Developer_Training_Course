_01_Printf.java — printf() 포맷 출력
System.out.printf()를 이용한 변수 값 형식화 출력 방법을 설명합니다. %d, %f, %s 등을 사용한 정수, 실수, 문자열 출력과 자릿수 지정, 소수점 자리수 제어 방법을 포함합니다.

_02_Variable.java — 변수 선언 및 출력
문자열, 정수, 문자 타입 변수 선언 및 초기화, 그리고 + 연산자와 printf()를 이용한 출력 방법을 보여줍니다.

_03_Variable2.java — 변수 값 교환
변수 간 값 교환을 위해 임시 변수를 사용하는 구조를 설명합니다.

_04_DataType.java — 데이터 타입
기본 정수형(byte, short, int, long)의 범위와 실수형(float, double)의 사용법을 설명합니다. float 사용 시 접미사 f의 필요성과 정수-실수 간 형 변환 가능성을 언급합니다.

_05_Char.java — 문자형 자료형 char
한 글자를 나타내는 char 타입의 사용법을 설명합니다. 문자에서 정수로 변환 시 유니코드 값이 출력됨을 보여줍니다.

_06_String.java — 문자열 타입 String
String이 객체이며 긴 문자열을 저장할 수 있음을 보여줍니다.

_07_TypeTrans.java — 형 변환 (Type Casting)
자동 형 변환(작은 타입 → 큰 타입)과 강제 형 변환(큰 타입 → 작은 타입)의 방법을 설명합니다. 강제 형 변환 시 오버플로우 발생 가능성을 경고합니다.

_08_Scanner.java — 입력 받기 (Scanner)
Scanner를 사용하여 사용자로부터 다양한 타입(int, String 등)의 입력을 받는 방법을 설명합니다. nextInt(), next() 메소드 사용법을 포함합니다.

_09_ScannerNextLine.java — next() vs nextLine()
next()와 nextLine()의 차이점을 설명합니다. next()는 단어 단위, nextLine()은 줄 전체를 입력받으며, nextInt() 등 사용 후 nextLine() 사용 시 개행 문자 문제 발생 가능성과 해결 방법을 제시합니다.

_10_Quiz.java — 입력 연습 퀴즈
사용자로부터 언어와 느낌을 입력받아 출력하는 퀴즈 예제입니다.

_11_Print.java — System.out.println()과 System.out.print()
System.out.println()과 System.out.print()의 차이점(줄 바꿈 여부)을 실습합니다.

_12_Out.java — printf() 사용법 학습
printf() 사용법을 학습하고, 정수(%d), 실수(%f), 문자열(%s)의 형식 지정 연습 및 응용 출력 포맷을 통한 컬럼 정렬을 실습합니다.

_13_Operator.java — 단항 연산자
단항 연산자(+x, -x)를 사용하여 음수/양수 표현을 실습합니다.

_14_Operator2.java — 증감 연산자 및 부정 연산자
증감 연산자(++, --)의 전위/후위 차이와 부정 연산자(!)를 실습합니다. 문자(char) 증감 연산으로 유니코드 다음 문자를 확인합니다.

_15_Operator3.java — 산술 연산자 및 복합 대입 연산자
산술 연산자(+, -, *, /, %)와 복합 대입 연산자(+=, -=, *=, %=)를 설명합니다. int 오버플로우 발생 가능성에 주의를 줍니다.

_16_Operator4.java — 비교 연산자 및 논리 연산자
비교 연산자(>, <, >=, <=, ==, !=)와 논리 연산자(AND &&, OR ||, XOR ^)를 설명하고 다양한 조합을 통한 불린 연산 확인을 실습합니다.

_17_Operator5.java — 삼항 연산자
삼항 연산자(조건식 ? 참 : 거짓)를 사용하여 조건에 따른 값 선택을 연습합니다.

_18_Quiz.java — 삼항 연산자 실전 예제
사용자로부터 키를 입력받고 삼항 연산자를 사용하여 "탑승 가능/불가능"을 출력하는 실전 예제입니다.
