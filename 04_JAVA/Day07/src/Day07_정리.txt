_04_Inheritance_public/Access01/DefaultC.java — default 접근 제어자 클래스
`_04_Inheritance_public.Access01` 패키지에 속하며 `default` 접근 제어자를 가지는 클래스입니다. 같은 패키지 내에서만 접근 가능한 클래스의 예시를 보여줍니다.

_04_Inheritance_public/Access01/Parent.java — protected 접근 제어자 예시
`_04_Inheritance_public.Access01` 패키지에 속하며 `protected` 접근 제어자를 가지는 `accessProtected()` 메소드를 포함하는 클래스입니다. `protected` 멤버는 같은 패키지 또는 다른 패키지의 자식 클래스에서 접근 가능함을 보여줍니다.

_04_Inheritance_public/Access01/PublicA.java — public 접근 제어자 클래스
`_04_Inheritance_public.Access01` 패키지에 속하며 `public` 접근 제어자를 가지는 클래스입니다. `private` 생성자와 `public` 메소드를 포함하며, 같은 패키지 내의 `DefaultC` 클래스 객체에 접근하는 예시를 보여줍니다.

_04_Inheritance_public/Access01/PublicD.java — private 생성자 접근 테스트
`_04_Inheritance_public.Access01` 패키지의 클래스로, `PublicA` 클래스의 `private` 생성자에 접근하려는 시도를 주석 처리된 코드를 통해 보여주며 `private` 접근 제어자의 제한을 설명합니다.

_04_Inheritance_public/Access02/Child.java — protected 멤버 접근 (상속 관계)
`_04_Inheritance_public.Access02` 패키지에 속하며 `Parent` 클래스를 상속받는 `Child` 클래스입니다. `accessProtected()` 메소드를 통해 부모 클래스의 `protected` 메소드에 접근하는 예시를 보여주며, 상속 관계에서의 `protected` 접근을 설명합니다.

_04_Inheritance_public/Access02/NotChild.java — protected 멤버 접근 (비상속 관계)
`_04_Inheritance_public.Access02` 패키지에 속하며 `Parent` 클래스를 상속받지만, `accessProtected()` 메소드를 통해 부모 클래스의 `protected` 메소드에 직접 접근하지 못하는 예시를 주석 처리된 코드를 통해 보여줍니다.

_04_Inheritance_public/PublicB.java — 접근 제어자 테스트 (다른 패키지)
`_04_Inheritance_public` 패키지의 클래스로, 다른 패키지(`_04_Inheritance_public.Access01`)에 있는 클래스(`PublicA`, `DefaultC`)에 접근하려는 시도를 주석 처리된 코드를 통해 보여주며 접근 제어자의 중요성을 암시합니다.

_05_Inheritance_camera/_0805_11_Final.java — final 키워드 활용
`final` 키워드가 필드와 메소드에 사용될 때의 동작을 보여주는 예제입니다. `final` 필드는 값을 변경할 수 없고, `final` 메소드는 오버라이드할 수 없음을 `ActionCam`과 `SlowActionCam`을 통해 설명합니다.

_05_Inheritance_camera/ActionCam.java — Camera 상속 (액션 카메라)

_05_Inheritance_camera/FactoryCam.java — Camera 상속 (공장 카메라)

_05_Inheritance_camera/Main.java — 다형성(Polymorphism) 활용

_05_Inheritance_camera/SpeedCam.java — Camera 상속 (과속 단속 카메라)
