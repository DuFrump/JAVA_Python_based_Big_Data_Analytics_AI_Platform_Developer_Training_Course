[1단계] 주제 선정 및 데이터 탐색
목표: 필요한 데이터를 불러오고, 각 데이터의 상태를 파악합니다.

할 일:

WHR 데이터 5개, GDP 데이터 1개, 수면 시간 데이터 1개를 모두 불러옵니다.

df.head(), df.info(), df.columns 코드를 사용해 각 데이터프레임의 첫 몇 행, 
컬럼 정보, 그리고 정확한 컬럼 이름을 확인합니다.



[2단계] 데이터 전처리
목표: 분석에 필요한 데이터만 남기고, 결측치와 불일치하는 컬럼 이름을 정리합니다.

할 일:

WHR 데이터: 2020년~2024년까지의 WHR 데이터 5개를 pd.concat()으로 합치고, 
Country name과 Ladder score, year만 남깁니다.

GDP 데이터: GDP 데이터에서 불필요한 열을 제거하고, country_name을 
Country name으로 바꿉니다.

GDP 결측치 처리: 2020년에 결측치가 있는 국가는 제거하고, 나머지 결측치는 
연도별 평균 성장률을 계산하여 채워 넣습니다.

수면 시간 데이터: country를 Country name으로 바꾸고, year 컬럼을 추가합니다.

최종 병합: pd.merge()를 사용해 WHR, GDP, 수면 시간 데이터를 Country name과 year를 
기준으로 합칩니다.



[3단계] 데이터 분석
목표: 프로젝트의 주요 질문에 답하기 위한 데이터를 계산합니다.

할 일:

2020년 대비 2024년 GDP 성장률을 기준으로, 상위 6개국과 하위 6개국을 선정합니다.

선정된 12개 국가의 데이터만 따로 필터링합니다.



[4단계] 시각화
목표: 분석 결과를 한눈에 파악할 수 있도록 그래프를 그립니다.

할 일:

경제 성장률과 행복 지수의 관계를 보여주는 **산점도(Scatter Plot)**를 그립니다.

수면 시간과 행복 지수의 관계를 보여주는 산점도를 그립니다.

수면 시간과 GDP의 관계를 보여주는 산점도를 그립니다.



[5단계] 인사이트 도출
목표: 그래프와 분석 결과를 바탕으로 결론을 내립니다.

할 일:

경제 성장률과 행복 지수 간의 상관관계가 있는지 정리합니다.

수면 시간과 행복 지수 간의 관계를 파악하고, GDP와의 관계와 비교하여 결론을 도출합니다.
