### 시간 자료형 (Time Data Types)
- [cite_start]Pandas에서 시간을 다루는 주요 자료형은 **`Timestamp`**와 **`Period`**입니다[cite: 1, 4].
- [cite_start]**Timestamp**: 특정 시점('2024-01-01')을 나타내는 자료형입니다[cite: 1, 4].
- [cite_start]**Period**: 특정 기간(2024년 1월)을 나타내는 자료형입니다[cite: 1, 3, 4].
- [cite_start]`pd.to_datetime()`: 문자열로 된 날짜를 **`Timestamp`** 객체로 변환합니다[cite: 1, 4, 5].

### 날짜/시간 인덱스 (Date/Time Index)
- [cite_start]`pd.date_range()`: Timestamp 배열을 생성합니다[cite: 2].
    - [cite_start]`freq` 옵션으로 간격(월초 'MS', 월말 'ME' 등)을 설정할 수 있습니다[cite: 2].
- [cite_start]`pd.period_range()`: Period 배열을 생성합니다[cite: 3].
- [cite_start]`set_index()`: 날짜/시간 컬럼을 DataFrame의 인덱스로 설정하면, 시간 순서에 따라 데이터를 다루기 편해집니다[cite: 1, 6].

### 시간 데이터 활용 및 추출
- [cite_start]`dt` 접근자: Timestamp 인덱스/시리즈에서 연, 월, 일 등 세부 정보를 추출합니다[cite: 4].
    - [cite_start]`dt.year`, `dt.month`, `dt.day`, `dt.hour`, `dt.minute`, `dt.second`[cite: 4].
- [cite_start]`to_period()`: Timestamp를 Period로 변환해 년, 월, 일 단위로 데이터를 나타낼 수 있습니다[cite: 1, 4].
    - [cite_start]`freq` 옵션을 사용해 변환할 기간의 단위('D', 'M', 'Y')를 지정할 수 있습니다[cite: 1, 4].

### 시계열 데이터 연산
- [cite_start]`shift()`: 행 데이터를 지정된 간격만큼 앞뒤로 이동시킵니다[cite: 6].
- [cite_start]`resample()`: 데이터의 시간 간격을 재조정하고, 그룹별로 집계(sum, mean, median 등)합니다[cite: 6, 11].
- [cite_start]`rolling()`: 특정 기간(`window`) 내의 데이터에 대한 이동 평균을 계산합니다[cite: 6].

### 데이터 전처리
- **누락 데이터 처리**:
    - [cite_start]`replace()`: '?'와 같은 누락 값을 `np.nan`으로 변경합니다[cite: 7, 10].
    - [cite_start]`dropna()`: `subset` 옵션으로 특정 컬럼의 누락값을 가진 행을 삭제합니다[cite: 9].
- **단위/타입 변환**:
    - [cite_start]`astype()`: 컬럼의 데이터 타입을 변경합니다[cite: 7, 10].
- **범주형 데이터**:
    - [cite_start]`np.histogram()`: 데이터를 구간별로 나눕니다[cite: 7].
    - [cite_start]`pd.cut()`: `np.histogram()`으로 나눈 구간에 따라 데이터를 분류하고 라벨을 붙여줍니다[cite: 7].
- **데이터 스케일링**:
    - [cite_start]`MinMaxScaler()`: 데이터를 0과 1 사이로 변환하여 스케일링합니다[cite: 7, 10].
    - [cite_start]`StandardScaler()`: 데이터의 평균을 0, 표준편차를 1로 변환하여 스케일링합니다[cite: 7, 10].

### 데이터프레임 조작
- **열 순서 바꾸기**: 컬럼 이름을 리스트로 만들고, 원하는 순서로 재배열하거나 `sorted()` 함수로 정렬하여 새로운 데이터프레임을 만들 수 있습니다.
- **문자열 분리 및 확장**:
    - `str.split()`: 문자열 컬럼의 값을 특정 문자를 기준으로 분리하여 리스트 형태로 반환합니다.
    - `expand=True` 옵션을 주면 분리된 문자열을 각각 새로운 열로 확장할 수 있습니다.

### 함수 적용하기
- **`map()`**: Series의 각 요소에 함수나 딕셔너리를 적용해 1:1로 값을 변환합니다.
    - DataFrame에 `map()`을 적용하면 모든 원소에 함수가 적용됩니다.
- **`apply()`**: Series나 DataFrame의 행 또는 열 전체를 함수에 전달하여 연산합니다.
    - `axis=0` (기본값): 각 열에 함수를 적용합니다.
    - `axis=1`: 각 행에 함수를 적용합니다.
- **`pipe()`**: 여러 함수를 파이프처럼 연결하여 코드를 체인처럼 작성할 수 있어 가독성을 높입니다.

### 그룹 연산
- **`groupby()`**: 특정 열을 기준으로 데이터를 그룹으로 나눕니다. 그룹화된 객체는 바로 데이터를 보여주지 않고 연산 함수를 기다립니다.
- **`agg()` (aggregate)**: 그룹별로 **집계 함수**(`min`, `max`, `mean` 등)를 적용해 그룹별로 요약된 결과를 반환합니다.
    - `agg()` 함수 내에 여러 함수를 리스트로 전달하거나, 컬럼별로 다른 함수를 적용할 수 있습니다.
- **`transform()`**: 그룹별로 연산을 적용하되, 원본 데이터와 **같은 크기**로 결과를 반환합니다.
    - 예를 들어, 각 그룹의 평균을 계산해서 원본 DataFrame의 새로운 열로 추가할 때 유용합니다.
    - `cumsum()`과 같은 누적 합 함수를 적용할 때도 사용됩니다.

### 데이터프레임 병합
- [cite_start]**`concat()`**: 여러 데이터프레임이나 시리즈를 하나로 합칩니다[cite: 4].
    - [cite_start]`axis=0` (기본값): 데이터를 세로로 이어붙입니다[cite: 4].
    - [cite_start]`axis=1`: 데이터를 가로로 이어붙입니다[cite: 4].
    - [cite_start]`ignore_index=True`: 기존 인덱스를 무시하고 새로운 인덱스를 부여합니다[cite: 4].
    - [cite_start]`join='inner'`: 공통된 열(세로 합치기) 또는 인덱스(가로 합치기)만 남깁니다[cite: 4].
- [cite_start]**`merge()`**: 공통된 열(key)을 기준으로 두 개의 데이터프레임을 합칩니다[cite: 5].
    - [cite_start]`how='inner'`: 교집합을 기준으로 합칩니다 (기본값)[cite: 5].
    - [cite_start]`how='outer'`: 합집합을 기준으로 합칩니다[cite: 5].
    - [cite_start]`how='left'`: 왼쪽 데이터프레임을 기준으로 합칩니다[cite: 5].
    - [cite_start]`how='right'`: 오른쪽 데이터프레임을 기준으로 합칩니다[cite: 5].
    - [cite_start]`on='컬럼명'`: 합치는 기준이 되는 컬럼을 지정합니다[cite: 5].

### 그룹 필터링 및 변형
- [cite_start]**`groupby().filter()`**: 그룹 연산의 결과에 따라 그룹 전체를 남기거나 버립니다[cite: 1].
    - [cite_start]`len(x)`로 그룹의 크기를 기준으로 필터링하거나, 특정 컬럼의 평균 등을 기준으로 필터링할 수 있습니다[cite: 1].
- [cite_start]**`groupby().apply()`**: 그룹별로 복잡하거나 통계적인 함수를 적용할 때 사용합니다[cite: 2].
- [cite_start]**`groupby().nth()`**: 그룹에서 첫 n번째 행을 선택합니다[cite: 1].

### 데이터프레임 재구조화

- [cite_start]**`stack()`**: 컬럼 인덱스를 행 인덱스(멀티 인덱스)로 변환합니다[cite: 7].

- [cite_start]**`melt()`**: 와이드(Wide)한 데이터프레임을 롱(Long)한 형태로 변환합니다[cite: 8].
