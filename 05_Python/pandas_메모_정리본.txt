### Pandas 핵심 요약

------------------------------------------------------------------------------------

### 1. 데이터프레임 기본

-   **생성 및 정보 확인**
    -   리스트나 딕셔너리를 사용해 DataFrame을 만들 수 있습니다.
    -   **head()**와 **tail()**은 데이터의 상위, 하위 5개 행을 보여줍니다.
    -   **info()**는 데이터프레임의 기본 정보를 출력합니다.
    -   **shape**는 행과 열의 크기를 나타냅니다.
    -   **describe()**는 각 열의 통계 정보를 요약해줍니다.
    -   **value_counts()**는 특정 열의 고유값 개수를 세어줍니다.

-   **데이터 선택 및 접근**
    -   **[]**: 한 개의 열 또는 여러 개의 열을 선택할 수 있습니다.
    -   **loc**: 인덱스/컬럼의 **이름**을 기준으로 데이터를 선택합니다.
    -   **iloc**: 행과 열의 **정수 위치**를 기준으로 데이터를 선택합니다.
    -   `:`를 사용한 슬라이싱으로 범위를 지정해 선택합니다.

-   **데이터 추가 및 수정**
    -   **열 추가**: `df['새로운 컬럼'] = 값` 형태로 값을 넣습니다.
    -   **행 추가**: `df.loc['새로운 인덱스'] = 값` 형태로 값을 넣습니다.
    -   **원소 값 변경**: `loc`나 `iloc`로 특정 위치를 선택하여 값을 바꿀 수 있습니다.

------------------------------------------------------------------------------------

### 2. 데이터 형태 변경

-   **인덱스/컬럼 관리**
    -   **rename()**: 인덱스나 컬럼의 **이름을 지정해서** 바꿉니다.
    -   **set_index()**: 특정 컬럼을 새로운 인덱스로 설정합니다.
    -   **reset_index()**: 기존 인덱스를 컬럼으로 올리고 새로운 정수 인덱스를 부여합니다.
    -   **reindex()**: 기존 개수와 종류에 상관없이 인덱스나 컬럼을 재생성합니다.

-   **데이터 정렬**
    -   **sort_index()**: 인덱스 순서로 정렬합니다.
    -   **sort_values()**: 특정 컬럼의 값 순서로 정렬합니다.

-   **열/행 삭제**
    -   **drop()**: `axis=0`은 행을, `axis=1`은 열을 삭제합니다.

------------------------------------------------------------------------------------

### 3. 데이터 전처리

-   **파일 입출력**
    -   **read_...()**: `csv`, `excel`, `json` 등 다양한 파일을 불러옵니다.
    -   **to_...()**: 데이터를 `csv`, `excel`, `json` 등으로 저장합니다.

-   **결측치/중복값 처리**
    -   **isnull()**: 결측치를 `True`로 표시합니다.
    -   **dropna()**: 결측치가 있는 행 또는 열을 삭제합니다.
    -   **fillna()**: 결측치를 특정 값으로 채웁니다.
    -   **duplicated()**: 중복된 행을 `True`로 표시합니다.
    -   **drop_duplicates()**: 중복된 행을 삭제합니다.

-   **데이터 타입 & 스케일링**
    -   **astype()**: 컬럼의 데이터 타입을 변경합니다.
    -   **replace()**: 특정 값을 다른 값으로 바꿉니다.
    -   **MinMaxScaler()**: 데이터를 0과 1 사이로 변환합니다.
    -   **StandardScaler()**: 평균을 0, 표준편차를 1로 변환합니다.

------------------------------------------------------------------------------------

### 4. 데이터 변환 & 재구성

-   **함수 적용**
    -   **map()**: **요소 단위 변환**. Series의 각 값을 변환합니다.
    -   **apply()**: **행/열 단위 연산**. DataFrame의 행이나 열 전체를 함수에 적용합니다.
    -   **pipe()**: **코드 가독성 향상**. 여러 함수를 연결합니다.
    -   **agg()**: **그룹별 연산**. 그룹별로 집계 함수를 적용합니다.
    -   **transform()**: 그룹별 연산을 적용하되, **원본과 같은 크기로** 반환합니다.

-   **데이터 재구조화**
    -   **melt()**: 와이드(Wide)한 데이터를 롱(Long)한 형태로 바꿉니다.
    -   **pivot_table()**: 데이터를 요약하고 행, 열, 값에 따라 재배치합니다.
    -   **stack()**: 컬럼 인덱스를 행 인덱스(멀티 인덱스)로 쌓습니다.
    -   **unstack()**: 행 인덱스를 컬럼 인덱스로 펼칩니다.

------------------------------------------------------------------------------------

### 5. 데이터 병합

-   **concat()**: 데이터를 **단순히 이어붙일 때** 사용합니다. `axis=0`으로 세로, `axis=1`로 가로로 합칩니다.
-   **merge()**: **공통된 키(Key)**를 기준으로 데이터를 합칠 때 사용합니다. `how` 옵션으로 방식을 정합니다.

------------------------------------------------------------------------------------

### 6. 그룹 연산 & 멀티 인덱스

-   **groupby()**: 특정 열을 기준으로 데이터를 그룹으로 나눕니다.
-   **filter()**: 그룹 연산의 결과에 따라 그룹 전체를 제거합니다.
-   **nth()**: 각 그룹에서 n번째 행을 선택합니다.

-   **MultiIndex 다루기**
    -   **MultiIndex**: 여러 레벨의 인덱스를 가진 구조입니다. `groupby()`로 생성할 수 있습니다.
    -   **선택**: `df.loc[('인덱스1', '인덱스2')]`처럼 튜플을 사용하거나, `df.xs()`로 특정 레벨의 값을 선택합니다.
    -   **정렬**: `sort_index(level=...)`로 특정 레벨을 기준으로 정렬할 수 있습니다.

------------------------------------------------------------------------------------

### 7. 시계열 데이터

-   **날짜/시간 자료형**: **Timestamp**는 특정 시점, **Period**는 특정 기간을 나타냅니다.
-   **to_datetime()**: 문자열을 Timestamp로 변환합니다.
-   **dt 접근자**: `dt.year`, `dt.month` 등으로 연, 월, 일 등 세부 정보를 추출합니다.
-   **resample()**: 시간 간격을 재조정하고 집계합니다.
-   **rolling()**: 특정 기간 내의 이동 평균을 계산합니다.
