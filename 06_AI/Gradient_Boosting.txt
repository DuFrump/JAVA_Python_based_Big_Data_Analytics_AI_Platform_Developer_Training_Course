//Gradient Boosting//

- 알고리즘 모델 중 하나이고, 회귀/분류 모두 작업이 가능함.
- 여러 개의 워크 모델을 순차적으로 구축해서 오류를 '보정'해 나감.
- 가중치를 조정하는 대신에 잔차를 최소화하는데 초점을 맞춤 (잔차 = 실제값 - 예측값) // 음의 기울기를 타겟으로 삼아서(오류를 가장 빠르게 줄일 수 있는 방향).
** 왜 음의 기울기만 타겟을 삼아야하는가?
-- 모델의 목표는 '손실 함수를 최소화'하는 것.
-- 최소값으로 향하는 방향을 항상 음의 기울기일 것이기 때문! 
(양의 기울기로 설정하게 되면 오히려 오차가 증가하는 방향이기 때문에 모델이 멍청해짐)
- 왜 gradient인가? 손실 함수는 예측과 실제값의 차이를 측정하는 함수
=> Gradient Boosting은 반복적으로 Weak model (일반적으로 Decision Tree)를 구축하고 (앙상블 모델의 기본), 잔차를 최소화하도록 최적화.
=> 이 과정에서 미분 또는 기울기가 최소화 되는 지점을 찾음.


Gradient Boosting 과정
1. 첫 번째 Weak model은 오리지널 데이터를 가지고, p1이라는 결과를 예측한다. 
그리고 실제와 p1의 차를 이용해 잔차를 계산.

2. 그럼 1에서 구한 그 잔차가 두 번째 Weak model의 y값(타겟값)이 된다. 
그럼 두 번째 모델은 기존 x(input 값)과 첫 번째 모델의 잔차(target 값)를 이용해 새로운 잔차를 계산한다.

3. .. 지정된 횟수만큼 모델이 생성되면 위 과정을 반복한다. (처음 실제 값 y에서 지속적으로 pn(n번째 예측값)을
빼주기 때문에 잔차는 지속적으로 감소하게 된다.


선형 회귀 모델 vs 그라디언트 부스팅
1. 단일 모델 vs 다중 모델 (단일 vs 앙상블)
2. 최적의 '가중치'를 한 번에 찾음 vs 잔차를 최소화 시켜가며 점진적으로 학습함
3. 선형 관계(단순한 관계) vs 비선형 관계(복잡한 관계)
4. 단순 해석과 예측 vs 최적의 값을 찾아 최고 성능 예측


랜덤 포레스트 vs 그라디언트 부스팅
1. 병렬적 vs 순차적
2. 분산 감소 vs 편향 감소 (값 예측 vs 잔차 줄이기)
3. 전체 트리 결과의 평균 or 다수결 vs 모든 트리의 누적 합


그럼 그라디언트 부스팅의 process는

1. t1에 진입
2. t1은 잔차를 계산 (r1 = Y - f1(X))

3. t2에 진입
4. r1을 target 삼아 t2를 학습시킴 (fit(X, r1))

5. 전체 앙상블 모델 업데이트
6. n번째 단계이기 때문에 f2(X) = f1(X) + η(설정한 학습률) * h2(X) ((T2가 예측한 r1의 값))

7. 이제 잔차를 t2가 예측함 r2 = Y - f2(X)

// rn = n 번째 잔차값
// fn(X) = 주택의 예측값
// hn(X) = n 번째 트리가 예측한 전 트리의 잔차
